# java-factory-demo

A deliberately small Java 21 library for pricing a shopping basket, used as
the target of the [agent factory](https://github.com/niallodwyerglobal/agent-factory).

```bash
./gradlew check
```

## Working with the agents

1. Open an issue describing a change.
2. Label it `agent:explore` to get findings, or `agent:implement` to go
   straight to a draft pull request.
3. The implement agent labels its PR `agent:review`; the review agent fixes
   what it can, comments on the rest, and marks the PR ready.
4. You read it and merge.

See [AGENTS.md](AGENTS.md) for what the agents are told about this repository
and [CODING_STANDARDS.md](CODING_STANDARDS.md) for what the reviewer enforces.
